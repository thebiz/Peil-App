# Peil (Arbeitstitel)

Suchen, Handy hochhalten, sehen wo's langgeht.

- Suche per Text oder Sprache (z. B. „Fielmann“, „Apotheke“, „S-Bahn“)
- Treffer schweben über dem Kamerabild in ihrer echten Richtung
- Unten: Pfeil zum nächsten Ziel, Entfernung, Gehzeit
- Marker antippen wählt ein anderes Ziel
- Ortsdaten: OpenStreetMap (kostenlos, kein Schlüssel nötig)

Die APK baut GitHub automatisch bei jedem Push (Reiter „Actions“ → letzter Lauf → „Peil-APK“).
